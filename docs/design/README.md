# Layout di riferimento (fonte di verità visiva)

Frame desktop 1920 (grid 12 col, margini 32, gutter 20) e mobile 375 (grid 4 col, margini 12, gutter 12). Il numero nel nome è la sezione (vedi `docs/sections.md`).

| File | Contenuto |
|---|---|
| `00-pagina-intera-desktop/mobile.png` | Panoramica a bassa risoluzione, tagliata a 8000 px: solo per orientarsi |
| `00-spec-pulsanti.png` | Tutti i pulsanti con stati (default, hover, pressed, focus, disabled), versioni con icona, pulsante navbar, select "3 Utenti" |
| `00-spec-navbar.png` | Navbar desktop, mobile chiusa, mobile aperta |
| `00-spec-stati-input.png` | Stati dei campi del form: default, hover, focus, errore |
| `01-hero-*` | Hero desktop e mobile (con striscia loghi) |
| `02-per-chi-*` | Per chi è pensato (desktop, mobile, riga di card in scroll) |
| `03-numeri-*` | I numeri parlano da soli |
| `04-carosello-*` | Tutto il necessario: desktop, mobile, le 6 card affiancate |
| `05-come-funziona-*` | Come funziona: desktop (tab Immobili), mobile (accordion), i 4 stati dei tab |
| `06-suite-*` | Una suite completa: desktop, mobile, riga di card |
| `07-piani-*` | I nostri piani + banner Prezzi chiari |
| `08-form-cta-footer-*` | Form di contatto, CTA finale, footer |

Nota: dove un frame mostra testi diversi da `docs/sections.md` (refusi, copy vecchio), vale `docs/sections.md`.
